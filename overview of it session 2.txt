1. What are the three main layers of software architecture? Write one line about each.

Presentation Layer – The part of the application that users see and interact with.
Business Logic Layer – Handles the rules, calculations, and main operations of the application.
Data Layer – Stores, retrieves, and manages data in the database.

2. Define client and server in your own words with one real-life example.

Client – A device or application that sends a request for a service or information.
Server – A computer or system that receives requests and provides the required data or service.
Example: When you open Instagram, your phone is the client and Instagram's servers provide the posts and other data.

3. Write 2 differences each between desktop apps, web apps, and mobile apps.

Desktop Apps:-
Installed directly on a computer.
Usually designed for Windows, macOS, or Linux.
Web Apps
Run through a web browser.
Usually do not require installation.
Mobile Apps
Designed for smartphones and tablets.
Usually installed through app stores.

4. Name any 3 databases and mention whether each is SQL or NoSQL.

MySQL – SQL database.
PostgreSQL – SQL database.
MongoDB – NoSQL database.
